# Aurelia — магазин колец

Статический сайт интернет-магазина колец: каталог с фильтрами по категориям, корзина на `localStorage` и оформление заказа.

## Структура

- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/app.js` — каталог товаров, корзина, модальные окна

## Запуск

Любой статический сервер, например:

```
python3 -m http.server 8080
```

и открыть `http://localhost:8080`.
